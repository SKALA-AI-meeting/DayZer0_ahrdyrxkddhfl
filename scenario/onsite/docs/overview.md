# 프로젝트 개요

## 우리 회사

- 브릿지시스템즈: 300명 규모 SI 회사. 고객사 시스템 구축·개선을 맡는다.
- 이번 프로젝트 인원: 정우진 팀장(프로젝트 PM, 본사 근무), 김하늘 컨설턴트(입사 2년 차, 고객사 상주), 오늘부터 함께 상주하는 신규 입사자 1명

## 고객사

- 한결물류: 택배·기업 물류 회사.
- 고객 문의의 40%가 "내 택배 어디쯤 왔나요"다. 배송 조회 화면이 불편하다는 불만이 많다.
- 고객사 담당: 운영기획팀 오상훈 과장(현업 담당), 운영기획팀 팀장(최종 결정)

## 이번 단계

- 배송 조회 화면(웹·모바일) 개선 요구사항을 정리해 다음 주 고객사 중간보고에서 확정한다.
- 개발은 요구사항 확정 뒤 다음 단계에서 한다.

## 상주 근무

- 고객사 사무실 3층 프로젝트 룸에서 일한다. 팀장은 본사에 있어 메신저로 연락한다.
