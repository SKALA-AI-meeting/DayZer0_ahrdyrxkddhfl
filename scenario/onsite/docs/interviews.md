# 현업 인터뷰 메모 (김하늘 작성 중)

지난주 한결물류 고객센터 상담원 4명, 운영기획팀 2명을 인터뷰했다.

## 주요 발언

| 대상 | 발언 |
|---|---|
| 상담원 A | "문의 대부분이 '언제 와요?'예요. 화면에 도착 예정 시간이 안 나와서요." |
| 상담원 B | "모바일에서 송장번호 입력하기가 너무 불편하대요. 붙여넣기가 잘 안 돼요." |
| 상담원 C | "배송 지연 안내가 없어서 고객이 화가 난 채로 전화해요." |
| 상담원 D | "웹 화면은 거의 안 써요. 고객 대부분이 휴대폰으로 봐요." |
| 운영기획 1 | "엑셀로 배송 현황을 내려받는 기능이 있으면 좋겠다는 기업 고객 요청이 있어요." |
| 운영기획 2 | "도착 알림을 카카오톡으로 받고 싶다는 요청이 많아요." |

## 정리 중

- 도착 예정 시간 표시, 모바일 송장 입력 개선, 지연 안내가 반복해서 나왔다.
- 엑셀 다운로드는 기업 고객 요청이라 이번 범위인지 확인이 필요하다.
