# 지표 현황 (지난달 기준)

## 전체

| 지표 | 값 |
|---|---|
| 월 사용자 | 30,000명 |
| 첫 모임 참여자 수 | 4,200명 |
| 첫 참여 후 30일 안에 두 번째 모임 참여 (재참여율) | **22%** |

## 모임 규모별 재참여율

| 첫 모임 인원 | 재참여율 |
|---|---|
| 5명 이하 | 31% |
| 6~10명 | 24% |
| 11명 이상 | 15% |

## 참고

- 첫 모임 후 모임 채팅에 한 번 이상 메시지를 남긴 사용자의 재참여율은 38%, 남기지 않은 사용자는 14%다.
- 재참여하지 않은 사용자 중 61%는 첫 모임 후 7일 안에 앱을 다시 열지 않았다.
- 오래 모임에 나오지 않은 사용자(휴면 사용자)의 지표는 아직 따로 집계하지 않는다. 데이터팀이 다음 주에 집계할 예정이다.
