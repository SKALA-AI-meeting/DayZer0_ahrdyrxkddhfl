# 사용자 인터뷰 요약

첫 모임에 참여한 사용자 8명을 인터뷰했다. 이 중 2명은 두 번째 모임에도 나왔고, 6명은 나오지 않았다.

## 주요 발언

| 참여자 | 재참여 | 발언 |
|---|---|---|
| A | 안 함 | "아는 사람이 없어 어색했다. 뛰고 나서 다들 아는 사이처럼 얘기하는데 끼기 어려웠다." |
| B | 안 함 | "다음 모임 일정을 놓쳤다. 앱을 안 열어서 언제 하는지 몰랐다." |
| C | 안 함 | "페이스가 나보다 빨라서 따라가기 힘들었다. 나한테 맞는 모임인지 미리 알고 싶었다." |
| D | 함 | "모임장이 끝나고 개인 메시지로 다음에도 오라고 해 줘서 다시 갔다." |
| E | 안 함 | "괜찮았는데 다시 신청하는 게 번거로웠다. 정기 모임이면 자동으로 잡혔으면 좋겠다." |
| F | 함 | "같은 동네 사람을 한 명 알게 돼서 같이 가기로 했다." |
| G | 안 함 | "다음 모임이 평일 저녁뿐이라 시간이 안 맞았다." |
| H | 안 함 | "첫 모임 후 아무 연락이 없어서 그냥 잊어버렸다." |

## 반복해서 나온 이야기

- 첫 모임에서 아는 사람이 없어 어색함 (A / 반대 사례: F)
- 다음 모임 일정을 놓치거나 잊음 (B, H)
- 다시 신청하는 과정이 번거로움 (E)
- 모임장·참여자의 개인적인 연결이 재참여로 이어짐 (D, F)
