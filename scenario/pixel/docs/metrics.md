# 지표 현황 (지난달 기준)

## 신규 유저

| 지표 | 값 |
|---|---|
| 신규 설치 | 2만 1천 명 |
| 튜토리얼 완료율 | 54% |
| 설치 7일 뒤 접속 비율 (7일 잔존율) | **18%** |

## 7일 잔존율 차이

| 구분 | 7일 잔존율 |
|---|---|
| 첫 주에 길드에 가입한 유저 | 41% |
| 길드에 가입하지 않은 유저 | 12% |
| 튜토리얼 3단계(첫 보스전)에서 2번 이상 진 유저 | 9% |

## 참고

- 신규 유저 이탈의 46%가 설치 첫날, 튜토리얼 3단계 전후에서 일어난다.
