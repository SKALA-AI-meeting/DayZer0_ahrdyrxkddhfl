# 유저 설문 요약

설치 7일 안에 접속을 멈춘 신규 유저 200명에게 설문했다(복수 응답).

## 결과

| 이탈 이유 | 응답 비율 |
|---|---|
| 튜토리얼이 길고 첫 보스전이 어려웠다 | 38% |
| 같이 할 사람이 없어 심심했다 | 27% |
| 무엇을 하면 보상을 받는지 몰랐다 | 19% |
| 결제를 해야 할 것 같은 압박을 느꼈다 | 16% |

## 주요 발언

- "첫 보스에서 세 번 지고 접었어요."
- "길드에 들어가 보려 했는데 어디로 들어가야 할지 몰랐어요."
- "출석 보상이 뭔지 잘 안 보였어요."
- "상자 뽑기 광고가 너무 많이 떠서 돈 쓰라는 게임 같았어요."
