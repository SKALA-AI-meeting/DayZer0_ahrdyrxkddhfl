# 지난주 라이브 운영 회의록

- 참석: 강민재(팀장), 윤하늘, 데이터팀 1명, 서버 리드 1명

## 결정 사항

1. **신규 유저 7일 잔존율(현재 18%)을 이번 분기 최우선 과제로 정한다.**
2. 다음 주에 이벤트·기능 기획안을 받아 개발 범위를 정한다.
3. 데이터팀이 이탈 유저 설문 결과를 요약해 공유한다.
4. 확률형 아이템 규제 대응으로 올해 보상 원칙을 확정했다(운영 정책 문서 참고).

## 논의 메모

- 신규 설치는 늘고 있지만 첫 주 이탈이 커서 월 이용자가 정체되어 있다.
- 길드 가입 유저의 잔존율이 높다는 데이터가 공유되었다.
