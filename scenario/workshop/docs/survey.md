# 작년 워크숍 설문 결과

작년 워크숍(1박 2일, 강원도 펜션) 참석자 26명 중 21명이 응답했다.

## 만족도

| 항목 | 만족 비율 |
|---|---|
| 전체 | 62% |
| 장소 | 71% |
| 프로그램 | 48% |
| 이동 | 33% |

## 주요 의견

- "이동만 왕복 6시간이라 너무 피곤했다." (비슷한 의견 9명)
- "팀 대항 레크리에이션이 길었다. 다른 팀 사람과 이야기할 시간이 더 있었으면." (7명)
- "1박은 좋았다. 저녁에 편하게 이야기한 시간이 제일 기억에 남는다." (6명)
- "아이가 있어서 1박이 부담스러웠다. 당일 일정도 선택할 수 있으면 좋겠다." (3명)

## 참석

- 전 직원 30명 중 26명 참석. 불참 4명 중 3명은 개발팀(출시 일정과 겹침).
